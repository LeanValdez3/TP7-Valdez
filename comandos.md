Git init: lo que hace es que convierte una carpeta en un repositorio.
Git clone: lo que hace es que copia un repositorio de GitHub a la compu.
Git status: lo que hace es que muestra qué cambió y qué está preparado para usarse.
Git add..: lo que hace es que prepara todos los cambios para el próximo commit.
Git commit: lo que hace es que guarda una version con un mensaje.
Git push: lo que hace es que sube los commits nuevos a GitHub.
Git pull: lo que hace es que trae los commits nuevos de github a la computadora.
Git branch: lo que hace es que crea una nueva rama sin nombre o muestra las que hay.
Git switch: lo que hace es que cambiamos la ruta a otra rama.
Git merge: lo que hace es que une la rama que estamos los commits de otra rama.
Git log: lo que hace es que muestra el historial de commits usados.
